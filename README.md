# 🏛️ SIRGEP

## Sistema Integral de Reservas y Gestión de Espacios Públicos

SIRGEP es una plataforma web desarrollada para apoyar a las municipalidades de Lima en la administración eficiente de espacios públicos, actividades recreativas y eventos municipales.

El sistema permite a los ciudadanos reservar espacios públicos, adquirir entradas para eventos y realizar pagos en línea mediante una plataforma centralizada. Asimismo, proporciona herramientas de gestión para administradores municipales, facilitando la automatización de procesos que tradicionalmente se realizan de manera manual.

---

## 🎯 Objetivo

Digitalizar y optimizar los procesos de reserva de espacios públicos y venta de entradas para eventos municipales, mejorando la experiencia de los ciudadanos y fortaleciendo la gestión administrativa de las municipalidades.

---

## ✨ Funcionalidades Principales

### 👤 Ciudadanos

* Registro e inicio de sesión.
* Reserva de espacios públicos.
* Consulta de horarios disponibles.
* Compra de entradas para eventos.
* Pago en línea mediante distintos métodos de pago.
* Descarga de constancias y comprobantes en PDF.
* Historial de reservas y entradas adquiridas.
* Cancelación de reservas según políticas establecidas.
* Calificación opcional de servicios.
* Selección de distrito preferido para recibir notificaciones.

### 🛠️ Administradores

* Gestión de espacios públicos.
* Gestión de eventos municipales.
* Administración de reservas.
* Administración de usuarios.
* Gestión de entradas y constancias.
* Calendario de reservas.
* Reportes descargables en PDF y Excel.
* Estadísticas del sistema.
* Eliminación lógica de registros inactivos.

---

## 🏗️ Arquitectura

El sistema fue desarrollado utilizando los principios de Programación Orientada a Objetos (POO) y una arquitectura por capas:

* Capa de Dominio
* Capa de Acceso a Datos
* Capa de Negocio
* Web Services
* Frontend Web

---

## 💳 Integraciones

* Izipay (simulación de pasarela de pagos)
* Sistema externo de notificaciones por correo electrónico

---

## 🗄️ Base de Datos

El modelo de datos fue diseñado en MySQL Workbench y contempla:

* Gestión de usuarios
* Reservas de espacios
* Eventos
* Entradas
* Pagos
* Notificaciones
* Calificaciones
